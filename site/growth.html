How this estimate works

Because the source provides annual—not monthly—returns, each annual return is converted to an equivalent monthly compounded rate. Your contribution is added at the start of each simulated month. Dividends are treated as reinvested. The chart is nominal and excludes fund fees, trading costs, taxes, and inflation.

*The annualized figure is a simple comparison of ending value with total dollars contributed. Because contributions arrive over time, it is not a personal investment return (IRR). Historical sequences are examples, not forecasts.
